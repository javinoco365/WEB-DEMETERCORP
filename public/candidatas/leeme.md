# Candidatas

Carpeta temporal para subir fotos sin filtrar. De aquí se eligen las
mejores, se recortan, se comprimen y se mueven a `public/images/`.
Esta carpeta se borra una vez hecha la selección.

Cómo subir: en GitHub, entra en esta carpeta, pulsa "Add file" y luego
"Upload files", arrastra las fotos y confirma con "Commit changes".
